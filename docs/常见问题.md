# 常见问题解答 (FAQ)

## 安装与配置

### Q1: 如何安装Python？

**A**:
1. 访问 [Python官网](https://www.python.org/downloads/)
2. 下载Python 3.8或更高版本
3. 安装时勾选 "Add Python to PATH"
4. 验证安装: 打开命令行输入 `python --version`

### Q2: 依赖包安装失败怎么办？

**A**:
```bash
# 方法1: 使用国内镜像
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 方法2: 逐个安装
pip install requests
pip install beautifulsoup4
pip install pandas
# ... 其他包

# 方法3: 使用conda
conda install pandas
conda install matplotlib
```

### Q3: 提示"ModuleNotFoundError"怎么办？

**A**:
```bash
# 确保在项目根目录运行
cd e:\自动化爬取房源

# 检查Python路径
python -c "import sys; print(sys.path)"

# 重新安装依赖
pip install -r requirements.txt --force-reinstall
```

### Q4: 如何验证安装成功？

**A**:
```bash
# 运行测试脚本
python tests/test_system.py

# 如果看到 ✅ 标记，说明安装成功
```

## 使用问题

### Q5: 双击启动.bat后闪退怎么办？

**A**:
1. 右键点击 `启动.bat` → 编辑
2. 在最后一行添加 `pause`
3. 保存并重新运行
4. 查看错误信息

或者直接在命令行运行:
```bash
python main.py
```

### Q6: 爬取速度太慢怎么办？

**A**:
修改配置文件 `config/settings.yaml`:
```yaml
crawl_settings:
  max_pages: 20      # 减少页数
  delay: 1           # 减少延迟（有风险）
```

详见 [性能优化指南](性能优化指南.md)

### Q7: 爬取不到数据怎么办？

**A**:
可能原因和解决方案:

1. **网络问题**
   ```python
   # 检查网络连接
   ping sanya.lianjia.com
   ```

2. **网站结构变化**
   - 查看日志文件 `logs/crawler_*.log`
   - 更新爬虫代码

3. **被反爬虫拦截**
   ```yaml
   # 增加延迟
   crawl_settings:
     delay: 3
   ```

4. **URL映射错误**
   - 检查 `spiders/` 目录下的区域映射
   - 更新拼音映射

### Q8: 如何只爬取某个区域？

**A**:
修改配置文件:
```yaml
districts:
  - "吉阳区"  # 只保留需要的区域
```

### Q9: 如何修改价格范围？

**A**:
```yaml

  min: 500000   # 50万
  max: 1500000  # 150万
```

或使用代码:

### Q10: 如何禁用某个网站？

**A**:
```yaml

  lianjia:
    enabled: true

    enabled: false  # 禁用58同城
```

## 数据问题

### Q11: 导出的Excel文件乱码怎么办？

**A**:
- 直接打开 `.xlsx` 文件（推荐）
- 如果打开CSV文件，选择UTF-8编码
- 使用WPS或Excel 2016+版本

### Q12: 数据重复怎么办？

**A**:
系统会自动去重，但如果仍有重复:
```python
import pandas as pd

df = pd.read_excel('output/房源数据.xlsx')
df = df.drop_duplicates(subset=['标题', '小区', '户型'], keep='first')
df.to_excel('output/去重后数据.xlsx', index=False)
```

### Q13: 如何合并多次爬取的数据？

**A**:
```python
import pandas as pd
import glob

# 获取所有Excel文件
files = glob.glob('output/三亚房源_*.xlsx')

# 合并
dfs = [pd.read_excel(f) for f in files]
merged = pd.concat(dfs, ignore_index=True)

# 去重
merged = merged.drop_duplicates(subset=['标题', '小区'], keep='last')

# 保存
merged.to_excel('output/合并数据.xlsx', index=False)
```

### Q14: 如何筛选特定条件的数据？

**A**:
```python
import pandas as pd

df = pd.read_excel('output/房源数据.xlsx')

# 筛选条件
filtered = df[
    (df['总价(万)'] >= 100) &
    (df['总价(万)'] <= 150) &
    (df['面积'] >= 90) &
    (df['区域'] == '吉阳区')
]

filtered.to_excel('output/筛选结果.xlsx', index=False)
```

## 错误处理

### Q16: 提示"ConnectionError"怎么办？

**A**:
网络连接问题，解决方案:
1. 检查网络连接
2. 检查防火墙设置
3. 使用代理
4. 增加超时时间:
   ```yaml
   crawl_settings:
     timeout: 60
   ```

### Q17: 提示"Timeout"怎么办？

**A**:
请求超时，解决方案:
```yaml
crawl_settings:
  timeout: 60      # 增加超时时间
  retry_times: 5   # 增加重试次数
```

### Q18: 提示"HTTP 403/404"怎么办？

**A**:
被网站拦截，解决方案:
1. 增加请求延迟
2. 使用代理池
3. 更换User-Agent
4. 暂停一段时间再试

### Q19: 提示"Permission denied"怎么办？

**A**:
文件权限问题，解决方案:
1. 以管理员身份运行
2. 关闭已打开的Excel文件
3. 检查文件夹权限

### Q25: 如何实现增量爬取？

**A**:
```python
import pandas as pd
from datetime import datetime

# 加载历史数据
try:
    old_df = pd.read_excel('output/最新数据.xlsx')
except:
    old_df = pd.DataFrame()

# 爬取新数据
engine = HouseCrawlerEngine()
result = engine.run()
new_df = result['dataframe']

# 合并去重
if not old_df.empty:
    combined = pd.concat([old_df, new_df])
    combined = combined.drop_duplicates(
        subset=['标题', '小区', '户型'],
        keep='last'
    )
else:
    combined = new_df

# 保存
combined.to_excel('output/最新数据.xlsx', index=False)
```
