## 开发流程

### 环境设置

```bash
# 1. Fork并克隆仓库
git clone https://github.com/your-username/house-crawler.git

# 2. 进入项目目录
cd house-crawler

# 3. 创建虚拟环境
python -m venv venv

# 4. 激活虚拟环境
# Windows
venv\Scripts\activate
# Linux/Mac
source venv/bin/activate

# 5. 安装开发依赖
pip install -r requirements.txt
pip install -r requirements-dev.txt  # 如果有

# 6. 运行测试
python tests/test_system.py
```

### 分支策略

- `main` - 主分支，稳定版本
- `develop` - 开发分支
- `feature/*` - 特性分支
- `bugfix/*` - 修复分支
- `hotfix/*` - 紧急修复分支

### 开发步骤

1. 从`develop`分支创建特性分支
   ```bash
   git checkout develop
   git checkout -b feature/new-feature
   ```

2. 编写代码和测试

3. 运行测试确保通过
   ```bash
   python tests/test_system.py
   ```

4. 提交代码
   ```bash
   git add .
   git commit -m "feat: add new feature"
   ```

5. 推送到远程
   ```bash
   git push origin feature/new-feature
   ```

6. 创建Pull Request到`develop`分支

## 代码规范

### Python代码规范

遵循 [PEP 8](https://pep8.org/) 规范：

```python
# 好的示例
def get_house_list(self, district: str, page: int = 1) -> List[Dict]:
    """
    获取房源列表

    Args:
        district: 区域名称
        page: 页码

    Returns:
        房源列表
    """
    houses = []
    url = f"{self.base_url}/{district}/page{page}"

    soup = self.get_page(url)
    if not soup:
        return houses

    for item in soup.select('div.house-item'):
        house = self._parse_house_item(item)
        if house:
            houses.append(house)

    return houses
```

### 命名规范

- **类名**: 大驼峰 `HouseCrawler`
- **函数名**: 小写下划线 `get_house_list`
- **变量名**: 小写下划线 `house_count`
- **常量**: 大写下划线 `MAX_RETRIES`
- **私有方法**: 单下划线 `_parse_item`

### 类型注解

使用类型注解提高代码可读性：

```python
from typing import List, Dict, Optional

def process_houses(
    houses: List[Dict],
    min_price: float = 0,
    max_price: float = float('inf')
) -> pd.DataFrame:
    """处理房源数据"""
    pass
```

### 文档字符串

使用Google风格的文档字符串：

```python
def calculate_statistics(df: pd.DataFrame) -> Dict:
    """
    计算数据统计信息

    Args:
        df: 房源数据框

    Returns:
        包含统计信息的字典，包括：
            - total_count: 总房源数
            - avg_price: 平均价格
            - median_price: 中位数价格

    Raises:
        ValueError: 如果数据框为空

    Example:
        >>> df = pd.DataFrame({'价格': [100, 150, 200]})
        >>> stats = calculate_statistics(df)
        >>> print(stats['avg_price'])
        150.0
    """
    if df.empty:
        raise ValueError("数据框不能为空")

    return {
        'total_count': len(df),
        'avg_price': df['价格'].mean(),
        'median_price': df['价格'].median()
    }
```

## 提交规范

使用 [Conventional Commits](https://www.conventionalcommits.org/) 规范：

### 提交格式

```
<type>(<scope>): <subject>

<body>

<footer>
```

### Type类型

- `feat`: 新功能
- `fix`: 修复bug
- `docs`: 文档更新
- `style`: 代码格式（不影响功能）
- `refactor`: 重构
- `perf`: 性能优化
- `test`: 测试相关
- `chore`: 构建/工具相关

### 示例

```bash
# 新功能
git commit -m "feat(spiders): add support for new website"

# 修复bug
git commit -m "fix(processor): fix data deduplication bug"

# 文档更新
git commit -m "docs(api): update API documentation"

# 性能优化
git commit -m "perf(crawler): optimize crawling speed"
```

## 测试规范

### 单元测试

为每个功能编写单元测试：

```python
import unittest
from spiders.lianjia import LianjiaSpider

class TestLianjiaSpider(unittest.TestCase):
    def setUp(self):
        self.spider = LianjiaSpider({
            'base_url': 'https://test.com',
            'name': '测试',
            'delay': 0
        })

    def test_parse_price(self):
        self.assertEqual(self.spider.parse_price("150万"), 150.0)
        self.assertEqual(self.spider.parse_price("200.5万"), 200.5)
        self.assertIsNone(self.spider.parse_price(""))

    def test_parse_area(self):
        self.assertEqual(self.spider.parse_area("120平米"), 120.0)
        self.assertEqual(self.spider.parse_area("90.5㎡"), 90.5)

if __name__ == '__main__':
    unittest.main()
```

确保测试覆盖率 > 80%:

```bash
# 安装coverage
```

## 文档规范

### 代码注释

- 复杂逻辑必须添加注释
- 注释应解释"为什么"而不是"做什么"
- 保持注释与代码同步

```python
# 好的注释
# 使用指数退避策略避免触发反爬虫机制
delay = base_delay * (2 ** attempt) + random.uniform(0, 1)

# 不好的注释
# 计算延迟
delay = base_delay * (2 ** attempt)
```
