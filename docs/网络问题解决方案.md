# 网络问题解决方案

## 问题描述

如果遇到"未获取到数据"或网络连接错误，可能的原因：

1. **网络连接问题** - 无法访问目标网站
2. **DNS解析失败** - 域名解析错误
3. **网站反爬虫机制** - 被网站拦截
4. **需要代理** - 需要配置代理服务器

## 解决方案

### 方案1：使用模拟数据测试（推荐）

系统提供了模拟数据模式，可以快速测试所有功能：

```bash
# 方式1：命令行
python main.py --mock

# 方式2：双击运行
使用模拟数据测试.bat
```

**优点：**
- 无需网络连接
- 快速测试系统功能
- 了解数据格式和处理流程

### 方案2：检查网络连接

1. **检查网络是否正常**
   ```bash
   ping sanya.lianjia.com
   ```

2. **检查防火墙设置**
   - 确保Python可以访问网络
   - 检查是否被防火墙拦截

3. **使用代理**
   - 如果需要代理，在配置文件中设置代理
   - 或使用VPN

### 方案3：更新网站URL

某些网站可能更换了域名，需要更新爬虫配置：

1. 打开 `config/settings.yaml`
2. 检查网站URL是否正确
3. 更新为正确的URL

### 方案4：使用其他数据源

系统支持多个网站，可以尝试：

1. 链家网
2. 安居客
3. 58同城
4. 贝壳找房

在配置文件中启用/禁用不同的网站。

## 模拟数据模式详细说明

### 生成模拟数据

模拟数据包含：
- 100条房源记录
- 吉阳区和天涯区
- 随机价格、面积、户型
- 符合真实数据格式

### 使用场景

1. **功能测试** - 测试系统所有功能
2. **界面预览** - 查看Web界面效果
3. **数据分析** - 了解数据统计功能
4. **导出测试** - 测试各种导出格式

### 模拟数据示例

```
标题: 三亚湾红树林 3室2厅 120平米
区域: 吉阳区
价格: 180万
面积: 120平米
户型: 3室2厅
来源: 链家
```

## Web界面使用模拟数据

在Web界面中，可以选择使用模拟数据：

1. 启动Web界面：`启动Web界面.bat`
2. 在控制面板中选择"使用模拟数据"
3. 点击"开始爬取"

## 真实爬取准备

要进行真实爬取，需要：

1. **稳定网络** - 确保可以访问目标网站
2. **合理频率** - 设置适当的请求间隔
3. **代理池** - 准备代理IP（可选）
4. **遵守规则** - 遵守网站robots.txt

### 配置建议

在 `config/settings.yaml` 中：

```yaml
crawl_settings:
  max_pages: 10        # 减少页数
  delay: 3             # 增加延迟
  timeout: 30          # 超时时间
  retry_times: 3       # 重试次数
```

## 常见错误

### 错误1: NameResolutionError
```
Failed to resolve 'sanya.lianjia.com'
```
**解决：** 检查DNS设置，或使用模拟数据模式

### 错误2: ConnectionError
```
Max retries exceeded
```
**解决：** 检查网络连接，或使用代理

### 错误3: 未获取到数据
```
未获取到数据
```
**解决：** 使用模拟数据模式测试，或检查网站结构变化

## 技术支持

如果问题持续存在：

1. 运行 `验证系统.bat` 检查系统状态
2. 查看 `logs/` 目录中的日志文件
3. 使用模拟数据模式测试功能
4. 检查网络配置和防火墙设置

## 推荐流程

1. **第一步：** 运行 `使用模拟数据测试.bat` 测试系统
2. **第二步：** 启动Web界面查看模拟数据
3. **第三步：** 检查网络连接
4. **第四步：** 配置代理（如需要）
5. **第五步：** 尝试真实爬取

---

**提示：** 模拟数据模式是测试和学习系统功能的最佳方式！
